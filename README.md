# Morning Line

One researched sports bet a day, with the reasoning and a running record. Live at https://johnfitz-z.github.io

## How it fits together

| Path | What it is |
|---|---|
| `data/picks.json` | Every pick and result. Rebuilt from the pick database by `model/export_site.py`. |
| `model/` | The pricing engine: margin removal, sport score models, blending, capped adjustments, Kelly staking, minimum price and closing line value. `model/METHOD.md` is the playbook. |
| `site/` | Website source: `templates/` (layout, pages, service worker), `assets/` (CSS and JavaScript modules), `static/` (icons, manifest), `site.json` (name and URL), `build.py` (the builder). |
| root `index.html`, `results/`, `stats/`, `bankroll/`, `method/`, `pick/`, `assets/`, `sw.js` | The built website that GitHub Pages serves. Generated by `site/build.py`; don't edit these by hand. |
| `tools/publish.py` | One step for the scheduled tasks: export the database to `data/picks.json`, then rebuild the site. |
| `tools/artifact/` | The single-page version that runs inside claude.ai. |

## Common jobs

- Rebuild the site after editing anything in `site/`: `python3 site/build.py`
- Publish a database export: `python3 tools/publish.py /tmp/ml/export`
- Test the pricing engine: `python3 -m unittest model/test_pricing.py`
- Use a custom domain: put it in `site/site.json`, add a `CNAME` file with the domain, rebuild, and point the domain's DNS at GitHub Pages.

The builder uses only the Python standard library. The pages are plain HTML, the scripts are ES modules, and nothing needs installing.
